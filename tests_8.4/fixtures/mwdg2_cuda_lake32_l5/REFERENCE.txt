CUDA reference snapshot for run_metal_mwdg2_cuda_hill.sh.

Generated by the CUDA MWDG2 solver on ECMWF HPC using the double-precision
build (_NUMERIC_MODE=1), LISFLOOD-FP 8.4 source, at t=0.2 s. Configuration:
32x32 DEM, cellsize 1, uniform free-surface elevation 11, one raised bed cell,
max_ref_lvl 5, epsilon 0.001, initial_tstep 0.05 s, fpfric 0.03,
limitslopes, tol_Krivo 1, outputs at 0.1 s intervals.

The regression compares the final depth and discharge rasters. CUDA depth is
stationary; CUDA Qx and Qy are roundoff-level zero. The Metal test uses the
same input and parameters and checks against this saved output with explicit
float-vs-double tolerances.
